Features

One email instead of twelve channels.

A FastAPI and Celery service reads Slack and writes the brief. A Next.js app handles sign-in, Add to Slack, the delivery time and billing.

Pick your hour

Choose when the brief arrives. The browser's time zone is saved with it, and an hourly job finds everyone who is due next.

Fixed sections, every day

Executive summary, achievements, blockers, incidents, deadlines, team updates, recommendations and action items, with owners by name.

Can't wait? Send one now

New users get a button that builds and sends a brief straight away, so nobody waits until tomorrow to see what it does.

Add to Slack with read-only history scopes. FocusGate only reads what that person can already read.
A team brief posted to one Slack channel every morning, if you set a channel ID.
A /focusgate command that posts a brief into the current channel on demand.
Stripe billing with checkout, customer portal and a subscription webhook. Optional.
How it works

From Slack history to one email.

  1. 01 · CONNECTAdd to SlackOne OAuth click with read-only history scopes. The token is stored per user.
  2. 02 · SCHEDULEPick a timeEvery hour Celery beat calls get_scheduled_users() and queues whoever is due in Redis.
  3. 03 · SUMMARISERead the last 24 hoursMessages from every readable channel, names resolved, then one structured Gemini prompt.
  4. 04 · DELIVERThe morning briefAn HTML email via Mailtrap, or a post in a Slack channel for the whole team.
Quick start

Run it on your own accounts.

You need Node 18+, Python 3.12, Poetry and Docker, plus Clerk, a Slack app, Gemini and Mailtrap. Stripe is optional.

git clone https://github.com/enzihub/focusgate && cd focusgate/web
# Postgres + local Neon HTTP proxy (see README for the two env vars)
docker compose -f src/db/docker-compose.yml up -d
cp .env.example .env.local && npm ci && npm run db:migrate
npm run dev                    # http://localhost:3000

cd ../core                      # fill in .env.development first
poetry install --no-root
poetry run uvicorn main:app --port 8000
poetry run celery -A app.core.scheduler.job_tasks worker
poetry run celery -A app.core.scheduler.job_tasks beat

Every value in the example env files is blank. The full setup, including the Slack scopes and the scheduler SQL, is in the README.
